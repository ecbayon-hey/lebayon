# Eddy notes

This file is the home for ad hoc field guidance from Eddy. Notes here are secondary to current public Klarna Network documentation, especially for API contracts and documented behaviour.

## Working principles

- Start troubleshooting by agreeing which environment, partner account, network session, request identifier, and timestamp are in scope.
- Separate documented platform behaviour from partner-specific implementation advice in explanations.
- Add dated notes and links where possible so temporary guidance is easy to reassess.
